# Northfall на Firebase: запуск за 15 минут

В папке два файла:
- `index.html` — сама игра, уже переделанная под Firebase;
- `firestore.rules` — правила доступа к базе (кто что может читать и менять).

## 1. Создать проект Firebase

1. Откройте https://console.firebase.google.com и войдите своим Google-аккаунтом.
2. «Создать проект» → название, например `northfall` → Google Analytics можно отключить → «Создать».

## 2. Включить вход по логину и паролю

1. Слева: **Build → Authentication** → «Начать».
2. Вкладка **Sign-in method** → **Email/Password** → включить первый переключатель → «Сохранить».

Игроки при регистрации вводят только логин и пароль. Почта им не нужна: игра сама превращает логин в адрес вида `логин@northfall.game`.

## 3. Создать базу данных

1. Слева: **Build → Firestore Database** → «Создать базу данных».
2. Регион: `eur3 (europe)` или ближайший к игрокам → режим **Production** → «Создать».
3. Вкладка **Правила (Rules)** → удалите всё, вставьте содержимое файла `firestore.rules` → **Опубликовать**.
4. Если ваш логин в игре не `shtorm1`, замените его в правилах в строке `function admin()`.

## 4. Получить ключи и вставить их в игру

1. Шестерёнка слева вверху → **Настройки проекта** → внизу «Ваши приложения» → значок `</>` (Web).
2. Название любое → «Зарегистрировать приложение». Firebase Hosting здесь не отмечайте.
3. Появится блок `const firebaseConfig = { ... }`. Скопируйте шесть значений (apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId).
4. Откройте `index.html` в любом текстовом редакторе. В самом начале найдите `FIREBASE_CONFIG` и замените каждое `ВСТАВЬ_СЮДА` своими значениями.
5. Там же в строке `const ADMINS=['shtorm1'];` должны стоять логины администраторов.

Ключ `apiKey` не секретный, его можно держать в открытом файле. Данные защищают правила из шага 3.

## 5. Выложить игру в интернет

Самый простой путь — **Netlify Drop**:
1. Откройте https://app.netlify.com/drop.
2. Перетащите туда **папку** с файлом `index.html`.
3. Через несколько секунд появится ссылка вида `https://что-то.netlify.app`. Это и есть адрес игры.
4. Зарегистрируйтесь на Netlify, чтобы сайт не удалился, и при желании задайте имя (`northfall.netlify.app`) или свой домен.

Другие варианты: GitHub Pages, Firebase Hosting, Vercel или ваш сайт на uCoz (загрузите `index.html` через файловый менеджер).

## 6. Разрешить вход с вашего адреса

Firebase → **Authentication → Settings → Authorized domains** → «Add domain» → впишите адрес сайта (например `northfall.netlify.app`). Без этого вход и регистрация на сайте не заработают.

## 7. Первый вход

Зайдите на сайт и **зарегистрируйтесь заново** с логином-администратором (например `shtorm1`). Герои из версии в Claude сами не переносятся: это другая база. Если нужен перенос, я могу выгрузить сохранения из Claude, а вы загрузите их в Firestore.

## Что важно знать

- **Бесплатный тариф Firebase (Spark)** держит примерно 50 000 чтений и 20 000 записей в день. Для начала этого хватит на десятки активных игроков. Если игроков станет много, понадобится тариф Blaze (оплата по факту использования).
- **Защита от читов.** Правила не дают трогать чужие сохранения и админку. Но золото и опыт по-прежнему считаются в браузере, и опытный игрок может подправить своё сохранение. Следующий шаг — перенести награды на сервер (Cloud Functions).
- **Восстановления пароля нет.** Поскольку почта у игроков «ненастоящая», письмо о сбросе не дойдёт. Админ может удалить аккаунт игрока в разделе Authentication, и тот зарегистрируется заново с тем же логином.
