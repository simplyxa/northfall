## Чего ещё НЕТ (важно)

- Драйвер `pg` добавлен в `package.json`, но `package-lock.json` не обновлён (в среде нет доступа к npm). `npm install` в Dockerfile и CI его подтянет сам; для порядка выполнить `npm install` локально и закоммитить lock.
- Импортёр разбирает 6 доменов: сохранения (`saves`), профили (`players`), кошельки и их журнал (`wallet`), рынок (`market`), кланы и их состав. **Все остальные документы** (форум, чат, письма `dm`, друзья, рейды, войны, мировой босс, платежи, промо и т.д.) сохраняются целиком в `migration_source_documents`, ничего не теряется, но игра пока не умеет их оттуда читать.
- Не написан слой доступа: игровой код (`server/saves.js`, `cycle.js`, `gold.js` и др.) всё ещё читает и пишет Firestore. Переключать нужно по одному домену за флагом, начиная с чтений.
- Импортёр проверен на синтетической выгрузке. Реальные документы могут отличаться: первый прогон на настоящей выгрузке даст отчёт о конфликтах и пропусках.

## Порядок (каждый шаг только с согласия владельца)

1. **Свежий день квоты.** Сразу после сброса (10:00 по Израилю).
2. **Экспорт.** `FIRESTORE_EXPORT_CONFIRM=YES EXPORT_MAX_DOCS=<лимит> node tools/firestore-export.js` на машине владельца. Секрет `FIREBASE_SERVICE_ACCOUNT` только в окружении, не в чате.
3. **Прогон импортёра:** `node tools/neon-import.js firestore-export neon-out`. Разобрать `import-report.json`: дубли имён и кланов (SQL при конфликтах не пишется), пропущенные документы, лидеры вне клана.
4. **Репетиция на `Northfall-test`:** применить `0001–0003`, затем `neon-import.sql` по direct-адресу. Сверка счётчиков встроена в транзакцию: если не сошлось, откат.
5. **Подключение пула на staging:** `DATABASE_URL` (pooled) только в секреты тестового окружения; `server/pg.js: smoke()` должен вернуть 43 таблицы.
6. **Переключение по доменам** (отдельные PR, каждый за флагом и с откатом): сначала чтения рейтингов и профилей, затем остальное. Кошельки, платежи, рынок и вещи — последними, с транзакциями и идемпотентностью.
7. **Окно обслуживания** для финальной синхронизации: объявление уже согласовано, но это не разрешение на переезд сейчас.

## Откат

Firestore не изменяется ни одним из шагов 1–5. До финального переключения откат — просто не включать флаг. Исходные документы лежат в `migration_source_documents` для сверки.

## Безопасность

- Строки подключения Neon — только в Fly secrets / GitHub Secrets; не в Git, логах и чате.
- Тестовую базу `Northfall-test` боевому приложению не давать.
- Для удаления аккаунтов нужно решение: анонимизация (`users.status='deleted'`) вместо `DELETE`, иначе внешние ключи блокируют удаление (платёжные записи хранить).
